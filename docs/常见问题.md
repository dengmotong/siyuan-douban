# 常见问题（FAQ）

> 排查任何问题前，建议先打开思源开发者工具查看控制台日志：
> `设置 → 关于 → 打开开发者工具`（桌面端），插件的关键错误都会 `console.error` 打印。

---

## 一、安装与启用

**Q：解压后思源里看不到插件？**
A：检查目录层级是否正确 —— 必须是 `工作空间/data/plugins/siyuan-douban/plugin.json`。
多套一层文件夹（例如 `siyuan-douban/package/plugin.json`）会导致思源识别不到。

**Q：启用后顶栏没有 📚 图标？**
A：`设置 → 集市 → 已下载` 里确认插件已启用；顶栏图标在右侧，可能被折叠进「更多」。

**Q：快捷键打不开？**
A：快捷键为 `⌘/Ctrl + Shift + ;`，**仅桌面端**。移动端会提示「移动端不支持快捷键开启」，请改用顶栏图标。

## 二、数据库相关

**Q：提示 `未找到对应的数据库块，请输入数据库视图块ID`**
A：块 ID 填错了或块已被删除。重新在属性视图块上右键 → 复制 → 复制块 ID。

**Q：提示 `该块不是有效的属性视图数据库块`**
A：你复制的是**普通文档块 / 段落块**的 ID。必须先插入 `/属性视图`（或 `/数据库`）块，再复制**该块**的 ID。

**Q：保存设置时数据库能过，但加书就报 `未找到数据库属性视图`**
A：通常是把同一个块 ID 填给了多个模块后又被改坏，或数据库被删除。重新校验一次，确保三个模块填的是三个不同的属性视图块。

**Q：列名被插件改了 / 多出一列？**
A：插件会补齐标准列名。如果你手动把「评分」改成别的名字，插件会认为缺失并**再新建**一个「评分」列。请保持列名与 [数据库字段说明](数据库字段说明.md) 一致。

**Q：主键列名没有变成「书名 / 电影名 / 剧名」？**
A：该操作依赖直接改写 `data/storage/av/{avID}.json`。无写权限环境（部分 Docker 部署、移动端）会静默失败，不影响使用。

**Q：数据库里出现空行？**
A：插件每次添加时会清理「主键列为空但其他列有值」的孤立行，属正常清理行为。

## 三、TMDB（电影 / 电视剧）

**Q：`请先在设置中填写 TMDB API Key`**
A：到 `用户设置 → TMDB API` 填入 Key 后，**务必点「保存设置」**（只填不保存不生效）。

**Q：`TMDB API Key 无效`**
A：常见三种原因：
1. Key 复制不完整或有空格；
2. 填成了 **API Read Access Token**（以 `eyJ` 开头的长串），应填 **API Key (v3 auth)**（32 位）；
3. 申请还没通过。

**Q：`TMDB 请求过于频繁，请稍后重试`**
A：触发了 TMDB 限流（HTTP 429），等一会儿再试。

**Q：搜不到我想看的片子 / 搜出来结果不对**
A：TMDB 对**日韩剧、国产老剧、综艺**的收录和中文译名不如豆瓣全，可尝试用**原名/英文名**搜索。
插件目前使用 TMDB 作为影视数据源，暂无豆瓣影视数据源。

**Q：`未找到该电影 / 电视剧`**
A：该 TMDB ID 已被合并或下架，重新搜索选择其他条目。

**Q：同一个 TMDB API Key 电影和电视剧都能用吗？**
A：可以，共用同一个 Key。

## 四、封面

**Q：添加后封面列为空**
A：封面由思源内核通过 `forwardProxy` 下载豆瓣 / TMDB 图片，网络不通时失败（控制台会有「封面自动下载失败」）。
此时可在表单里点 **📁 上传封面** 手动上传，文件会存到 `assets/covers/`。

**Q：表单里能看到封面，但数据库里没有**
A：表单里显示的是远程图片预览；只有添加成功且下载成功才会写入资源列。

**Q：能不能关掉自动下载封面？**
A：当前版本无此开关。自动下载失败会自动降级为空值，不会中断添加流程。

## 五、笔记生成

**Q：勾选了「生成笔记」但没有生成文档**
A：检查：
1. 数据库块所在的文档必须存在（插件用它的 `hpath` 作为笔记父路径）；
2. 控制台是否有 `创建观影/追剧笔记失败`；
3. 数据库行是否创建成功（笔记挂在数据库行上）。

**Q：笔记内容和模板不一样 / 变量没替换**
A：检查变量名是否与 [模板变量参考](模板变量参考.md) 完全一致（含全角括号、`/` 等）。
变量在**添加记录时**替换，改模板不会影响已生成的旧笔记。

**Q：`SY模板渲染` 是什么？要不要开？**
A：开启后会用思源自身的模板引擎二次渲染生成内容，适合在模板里使用思源原生模板语法。
不使用思源模板语法时保持关闭。

**Q：模板保存后没生效？**
A：模板编辑器里点保存 → 再回到设置页点 **`保存设置`**（两处都会写入 `settings.json`，建议都点一次）。

## 六、网页版 / 浏览器端

**Q：网页版能搜索书籍吗？**
A：可以。书籍搜索走思源内核 `/api/network/forwardProxy` 转发豆瓣请求，不依赖 Electron。

**Q：网页版能扫码登录微信读书吗？**
A：不能。扫码依赖 Electron，请使用「填写 Cookie」方式。

**Q：网页版能上传封面吗？**
A：可以，走 `/api/file/putFile`。

**Q：网页版搜书没结果 / 报网络错误**
A：确认服务器（或本机）能访问 `search.douban.com`；豆瓣风控可能返回验证码页，此时解析不到结果，稍后再试。

## 七、微信读书

**Q：提示 `登录已过期`**
A：重新扫码或更新 Cookie。

**Q：`请先设置微信读书笔记同步模板`**
A：到微信读书标签页设置笔记模板后再同步。

**Q：`请先进行一次全部同步后再更新同步！`**
A：增量同步需要基线，先点「全部同步」。

**Q：有些书一直同步不进来**
A：检查是否被加入了「忽略书籍」；没有 ISBN 的书需要在「自定义ISBN书籍」里指定 ISBN，或用「bookID同步书籍」关联。

**Q：同步的笔记插入在哪里？**
A：插入在文档中的「位置标记」之后，可在微信读书设置里修改标记文本。

---

## 八、去重与数据

**Q：`电影已存在，跳过添加操作` / `电视剧已存在，跳过添加操作`**
A：按 `IMDb编号` 去重（为空时回退 TMDB 链接）。想强制新增，先在数据库里删除该行，或清空其 IMDb编号。

**Q：同一部片想记录多次观看（二刷）怎么办？**
A：当前一个条目只能有一行。可先删除旧行再添加，或手动在笔记里补记。

**Q：书籍按什么去重？**
A：`ISBN`。没有 ISBN 的书建议用「bookID / 自定义 ISBN」方式管理。

## 九、其它

**Q：插件会不会联网上传我的数据？**
A：不会。所有请求都是**从你的设备**发往豆瓣 / TMDB / 微信读书，数据只写入你本地的思源工作空间。

**Q：如何完全重置插件设置？**
A：关闭插件后删除 `工作空间/data/storage/petal/siyuan-douban/settings.json`，再启用插件重新配置。
（注意：`weread_*`、`INTP` 等文件也在同目录，删除会影响微信读书登录状态与「不再提示」。）

**Q：还是解决不了？**
A：请附上**思源版本号、插件版本、操作步骤、控制台报错截图**，在仓库提 issue：
<https://github.com/dengmotong/siyuan-douban/issues>
