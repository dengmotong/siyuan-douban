# 模板变量参考

插件支持五套模板，均可自由编辑：

| 模板 | 作用 | 打开位置 |
| --- | --- | --- |
| 读书笔记模板 | 添加书籍时生成笔记文档 | 用户设置 → 📝 设置模板 |
| 观影笔记模板 | 添加电影时生成笔记文档 | 用户设置 → 📝 设置电影笔记模板 |
| 追剧笔记模板 | 添加电视剧时生成**总**笔记文档 | 用户设置 → 📝 设置电视剧笔记模板 |
| 分集笔记模板 | 勾选「生成分集笔记」后，为**每一集**生成一个笔记文档 | 用户设置 → 📺 设置分集笔记模板 |
| 微信读书笔记模板 | 同步微信读书笔记时写入书籍文档 | 微信读书 → 设置模板 |

变量统一使用 `{{变量名}}` 语法。变量在**添加记录的那一刻**替换，因此模板改动只影响之后新增的记录。

## 四、分集笔记模板变量

分集笔记模板**可以使用上面「三、追剧笔记模板变量」里的全部变量**（它们表示整部剧的信息），
另外额外支持下列**分集变量**：

| 变量 | 说明 |
| --- | --- |
| `{{当前季}}` | 本集所属季号，正片从 `1` 开始，如 `2` |
| `{{当前集}}` | 本集集号，如 `7` |
| `{{季集}}` | 季集简写，如 `S02E07`（补零两位） |
| `{{集标题}}` | 本集标题（TMDB 分集名，可能为空） |
| `{{集简介}}` | 本集剧情简介 |
| `{{集播出日期}}` | 本集首播日期，如 `2023-01-15` |
| `{{集时长}}` | 本集时长，如 `45分钟` |
| `{{集剧照}}` | 本集剧照地址（TMDB 远程 `w300` 图片 URL，可能为空） |
| `{{集评分}}` | 本集 TMDB 评分（为空时「无评分」） |
| `{{集评分人数}}` | 本集评价人数（为空时 `0`） |

> ⚠️ **注意区分**：`{{季数}}` / `{{集数}}` 表示**整部剧**的总季数、总集数（与总模板一致），
> 本集的季号、集号请用 `{{当前季}}` / `{{当前集}}`。

默认模板（可在设置里修改）：

```markdown
# 📺 {{剧名}} 第{{当前季}}季 第{{当前集}}集 {{集标题}}

![]({{集剧照}})

- 播出日期：{{集播出日期}}
- 时长：{{集时长}}
- 评分：{{集评分}}（{{集评分人数}} 人评价）

---

## 剧情简介
{{集简介}}

---

## 本集笔记
### ✍️ 观剧心得
（在此记录你对本集的感受）
```

## 五、微信读书笔记模板变量

微信读书模板分为**书籍信息**与**笔记内容**两部分，支持区块（section）语法：区块内容为空时，整块会被移除。

### 4.1 书籍信息变量

| 变量 | 说明 |
| --- | --- |
| `{{书名}}` | 书名 |
| `{{副标题}}` | 副标题 |
| `{{原作名}}` | 原作名 |
| `{{作者}}` | 作者 |
| `{{译者}}` | 译者 |
| `{{出版社}}` | 出版社 |
| `{{出版年}}` | 出版时间 |
| `{{出品方}}` | 出品方 |
| `{{丛书}}` | 丛书 |
| `{{ISBN}}` | ISBN |
| `{{装帧}}` | 装帧 |
| `{{定价}}` | 定价 |
| `{{页数}}` | 页数 |
| `{{封面}}` | 封面 |
| `{{豆瓣评分}}` | 豆瓣评分 |
| `{{评分人数}}` | 豆瓣评价人数 |
| `{{微信读书评分}}` | 微信读书推荐值 |
| `{{微信读书评分人数}}` | 微信读书评分人数 |
| `{{我的评分}}` | 我的评分 |
| `{{书籍分类}}` | 书籍分类 |
| `{{阅读状态}}` | 阅读状态 |
| `{{开始日期}}` | 开始阅读日期 |
| `{{读完日期}}` | 读完日期 |

### 4.2 笔记区块（section）语法

| 区块 | 说明 |
| --- | --- |
| `{{#chapters}} … {{/chapters}}` | 遍历所有章节，块内可用 `{{chapterTitle}}` |
| `{{#notes}} … {{/notes}}` | 遍历本章笔记，块内可用 `{{highlightText}}` / `{{highlightComment}}` |
| `{{#chapterComments}} … {{/chapterComments}}` | 本章的章节评论，块内用 `{{chapterComments}}` |
| `{{#globalComments}} … {{/globalComments}}` | 全书评论 |
| `{{#bookInfo}} … {{/bookInfo}}` | 书籍简介，块内用 `{{bookInfo}}` |
| `{{#AISummary}} … {{/AISummary}}` | 微信读书 AI 摘要，块内用 `{{AISummary}}` |
| `{{#bestHighlights}} … {{/bestHighlights}}` | 热门划线，块内用 `{{bestHighlight}}` |

### 4.3 笔记行内变量

| 变量 | 说明 |
| --- | --- |
| `{{chapterTitle}}` | 当前章节标题 |
| `{{notebookTitle}}` | 书名 |
| `{{highlightText}}` | 划线原文 |
| `{{highlightComment}}` | 划线对应的想法 / 评论 |
| `{{content}}` | 评论内容（简写，等同 `highlightComment`） |
| `{{markText}}` | 划线文本（简写，等同 `highlightText`） |

> 💡 **重要行为**：若某行包含 `{{highlightComment}}`，当一条笔记**只有划线、没有评论**时，该行会被整行丢弃。
> 因此建议把「划线」和「评论」写成两行，例如：
>
> ```markdown
> > {{highlightText}}
>
> 💬 {{highlightComment}}
> ```

### 4.4 完整示例

```markdown
# 📖 {{书名}}

![]({{封面}})

- 作者：{{作者}}
- 出版社：{{出版社}}
- ISBN：{{ISBN}}
- 微信读书评分：{{微信读书评分}}

{{#bookInfo}}
## 简介
{{bookInfo}}
{{/bookInfo}}

---

## 划线笔记

{{#chapters}}
### {{chapterTitle}}

{{#notes}}
> {{highlightText}}

💬 {{highlightComment}}
{{/notes}}

{{#chapterComments}}
**章节评论**：{{chapterComments}}
{{/chapterComments}}

{{/chapters}}

{{#globalComments}}
## 全书评论
{{globalComments}}
{{/globalComments}}
```

## 六、SY模板渲染开关

在 `用户设置` 中勾选 **「SY模板渲染」** 后，生成笔记的流程会变为：

1. 仍然按上面的变量替换模板文本；
2. 把渲染结果写入 `工作空间/data/storage/petal/siyuan-douban/{book|movie|tv|tvEpisode}NoteTemplate.md`；
3. 调用思源 `/api/...render` 用思源自身的模板引擎再渲染一次，并写入文档。

该开关对**读书 / 观影 / 追剧 / 分集**四套笔记模板都生效，分集笔记逐集渲染（复用同一个临时文件）。

适合需要在模板里使用思源原生模板语法（如 `<% %>`、挂件、查询嵌入等）的场景。若不使用思源模板语法，保持关闭即可。
