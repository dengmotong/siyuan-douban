## 1. 打开插件

| 方式 | 操作 |
| --- | --- |
| 顶栏图标 | 点击右侧顶栏的 📚 图标 |
| 快捷键 | 桌面端 `⌘/Ctrl + Shift + ;`（**移动端不支持**，会提示错误） |

首次打开会弹出欢迎 / 教程对话框，可勾选「不再提示」。
插件面板共 6 个标签页：**书籍查询、电影查询、电视剧查询、用户设置、微信读书、关于插件**。

## 2. 首次配置

### 2.1 创建三个数据库（属性视图）

1. 新建一个文档（例如「我的书影音」）。
2. 输入 `/属性视图` 回车，插入属性视图块。
   - 想要三个独立数据库就插三个块；也可以只建一个，但**不要三个模块填同一个块 ID**。
3. 点击块左上角菜单 → `复制` → **复制块 ID**。

### 2.2 填写插件设置

打开插件 → `用户设置`：

```
书籍数据库块ID：   ← 粘贴书籍属性视图块 ID
🎬 电影数据库      ← 粘贴电影属性视图块 ID
📺 电视剧数据库     ← 粘贴电视剧属性视图块 ID
TMDB API Key      ← 见 2.3
```

点击 **`保存设置`**。校验通过会显示 `数据库验证通过 ✅`，同时插件自动补齐所有字段列。

### 2.3 申请 TMDB API Key

1. 访问 <https://www.themoviedb.org/signup> 注册账号。
2. 访问 <https://www.themoviedb.org/settings/api>，点击 **Request an API Key**。
3. 类型选择 **Developer**，按要求填写用途（个人笔记管理即可）。
4. 申请通过后，复制 **API Key (v3 auth)**（32 位字符串）。
5. 粘贴到 `TMDB API` 输入框 → `保存设置`。

> ⚠️ 电影与电视剧共用同一个 Key。请勿填写 v4 的 **API Read Access Token**（那种以 `eyJ` 开头的长串），插件会报 `TMDB API Key 无效`。

## 3. 书籍查询

### 3.1 两种查询方式

**A. 用 ISBN 直查（最准）**

在输入框输入 ISBN，例如 `9787115428028`，回车或点 🔍。
插件通过 `book.douban.com/isbn/{isbn}` 拉取详情页并解析。

**B. 用书名搜索**

输入书名，例如 `深入理解计算机系统`，回车后会弹出搜索结果窗口：

- 结果来自 `search.douban.com/book/subject_search`，包含封面、作者、出版社、出版年、评分、评分人数。
- 点击任意结果 → 自动再抓取该书的详情页 → 填充表单。
- 若搜索无结果，可点「重试」。

> 网页版（浏览器端）同样支持以上两种方式：插件通过思源的 `forwardProxy` 转发请求，不依赖 Electron。

### 3.2 填写表单

表单字段可任意修改。下方需要选择：

| 字段 | 说明 |
| --- | --- |
| 我的评分 | 来自设置里的「评分等级」列表 |
| 书籍分类 | 来自设置里的「书籍分类」列表 |
| 阅读状态 | 想读 / 在读 / 已读 |
| 开始日期 / 读完日期 | 日期选择器 |
| 生成读书笔记 | 勾选后添加时同步创建笔记文档 |

**封面**：插件会尝试自动下载封面到 `assets/covers/`。若下载失败（网络 / CDN 限制），封面列为空，此时可点 **📁 上传封面** 手动上传（保存到 `assets/covers/` 并写入 `assets/covers/xxx` 路径）。

### 3.3 添加

点 **`✅添加书籍`**：

- 成功：提示 `✅《书名》已加入书库`，数据库自动刷新，表单清空。
- 已存在：提示 `❌ 保存失败: 书籍已存在，跳过添加操作`（按 ISBN 去重）。

## 4. 电影查询

1. 切到 `🎬 电影查询`。
2. 输入片名 → 🔍 → 弹窗展示 TMDB 结果（海报、评分、评分人数、首播/上映年、简介）。
3. 点选目标电影 → 自动拉取详情并填入表单。
4. 核对并修改字段；选择 `我的评分 / 电影分类 / 观影状态`，设置 `开始日期 / 看完日期`，勾选 `生成观影笔记`。
5. 点 `✅添加电影`。

**去重**：默认按 `IMDb编号` 比对；TMDB 没有 IMDb 数据时回退比对 TMDB 链接。

**字段说明**

| 表单字段 | 说明 |
| --- | --- |
| 电影名 | TMDB `title`，写入主键列 |
| 原名 | TMDB `original_title` |
| 导演 / 编剧 | 来自演职员表 |
| 主演 | 演员表前 8 位 |
| 片长 | 形如 `120分钟` |
| IMDb | 形如 `tt0111161` |
| 链接 | `https://www.themoviedb.org/movie/{id}` |

## 5. 电视剧查询

流程与电影完全一致，差异在字段：

| 表单字段 | 说明 |
| --- | --- |
| 剧名 | TMDB `name`，写入主键列 |
| 首播日期 | `first_air_date` |
| 季数 / 集数 | `number_of_seasons` / `number_of_episodes` |
| 单集片长 | `episode_run_time` 第一项，形如 `45分钟` |
| 电视台 | `networks`，如 `CCTV-8, 腾讯视频` |
| 追剧状态 | 想在 / 在看 / 已看 / 弃剧（可在设置中自定义） |

> 剧集通常没有单一「导演」，插件优先使用 TMDB 的 **创作者（created_by）** 填入导演列，并回退到演职员表中 `job = Director` 的记录。

**去重**：与电影一致，优先 `IMDb编号`。

### 5.1 分集笔记（可选）

表单底部有两个独立勾选项，可任意组合：

| 勾选 | 结果 |
| --- | --- |
| `生成追剧笔记` | 生成一个**总**的追剧笔记文档（绑定到数据库行） |
| `生成分集笔记` | 为**每一集**生成一个独立的小笔记文档，方便分集记录 |
| 两个都勾 | 先建总笔记，再在总笔记下面挂分集笔记 |
| 都不勾 | 只写入数据库行，不生成任何文档 |

生成后的目录结构：

```
（属性视图所在的文档）
└── 三体/                     ← 总笔记（数据库行绑定的文档）
    ├── 第1季/                 ← 按季自动分组
    │   ├── 第01集 剧集名
    │   ├── 第02集 剧集名
    │   └── …
    └── 第2季/
        └── …
```

要点：

- 分集信息来自 TMDB `/tv/{id}/season/{n}`，会自动拉取**所有季**，季文件夹由思源自动创建。
- **TMDB 第 0 季（特别篇）默认跳过**，不属于正片剧集。
- 集标题为空时只显示 `第NN集`；集号补零成两位以保证排序。
- 生成过程中右下角会显示进度（如 `⏳ 分集笔记 5/42`）。
- 分集模板在 `用户设置 → 📺 设置分集笔记模板`，变量见 [模板变量参考 → 分集笔记](模板变量参考.md#四分集笔记模板变量)。
- 长剧集（200+ 集）会创建大量文档且耗时较久，建议只对正在追的剧开启。

> ⚠️ 分集笔记只在**添加电视剧时**生成一次。若想补生成，先在数据库里删掉该行、再重新添加；也可以手动在总笔记下新建文档。

## 6. 微信读书同步

### 6.1 登录

`📗 微信读书` 标签页提供两种方式：

| 方式 | 说明 |
| --- | --- |
| 扫码登录 | 仅桌面端可用（需要 Electron） |
| 填写 Cookie | 手动粘贴微信读书网页版 Cookie，任意端可用 |

登录成功后会显示欢迎信息与截止同步时间。

### 6.2 同步

- **全部同步**：拉取全部书籍与笔记。
- **更新同步**：仅同步上次同步时间之后有更新的书籍（需先做过一次全部同步）。

同步写入位置由 `位置标记` 决定，笔记内容插入在文档中该标记之后。模板见 [模板变量参考 → 微信读书](模板变量参考.md#五微信读书笔记模板变量)。

### 6.3 三类例外管理

| 功能 | 说明 |
| --- | --- |
| 自定义ISBN书籍 | 微信读书没有 ISBN 的书籍，可手动指定 ISBN，以便与豆瓣书籍合并 |
| 忽略书籍 | 同步时跳过指定书籍（按 bookID 或 ISBN 匹配） |
| bookID同步书籍 | 用微信读书的 bookID 而非 ISBN 关联书籍 |

### 6.4 自动同步

在微信读书设置里开启 `启动同步` 后，思源启动、布局就绪时会自动执行一次同步（若登录过期会提示重新扫码）。

## 7. 设置项说明

`⚙️ 用户设置` 页面完整字段：

| 区域 | 字段 | 说明 |
| --- | --- | --- |
| 书籍 | 书籍数据库块ID | 属性视图块 ID |
| 书籍 | 评分等级 / 书籍分类 / 阅读状态 | 逗号分隔（中英文逗号均可），会显示为下拉选项 |
| 书籍 | 默认生成读书笔记 | 新增书籍时默认勾选 |
| 书籍 | 设置模板 / SY模板渲染 | 见模板参考 |
| 电影 | 电影数据库块ID | 属性视图块 ID |
| 电影 | TMDB API Key | 电影 + 电视剧共用 |
| 电影 | 电影评分等级 / 电影分类 / 观影状态 | 逗号分隔 |
| 电影 | 设置电影笔记模板 | 模板编辑器 |
| 电视剧 | 电视剧数据库块ID | 属性视图块 ID |
| 电视剧 | 电视剧评分等级 / 电视剧分类 / 追剧状态 | 逗号分隔 |
| 电视剧 | 设置电视剧笔记模板 | 模板编辑器（总笔记） |
| 电视剧 | 设置分集笔记模板 | 模板编辑器（分集笔记） |

> 所有设置统一保存在 `工作空间/data/storage/petal/siyuan-douban/settings.json`，点击 `保存设置` 一次性写入。

## 8. 推荐工作流

1. **一次性**：建好三个属性视图 → 填 ID → 填 TMDB Key → 保存 → 调整评分/分类/状态下拉项。
2. **模板先行**：先在设置里把三套笔记模板改成自己喜欢的样式，再开始批量添加。
3. **书籍**：优先用 ISBN 录入，避免同名书选错。
4. **影视**：用 TMDB 搜索，录入后按需补齐「我的评分 / 状态 / 起止日期」。
5. **微信读书**：先「全部同步」建立基线，之后定期「更新同步」。
6. **看板**：把三个数据库块放到同一文档，或将数据库嵌入日记/主页，用属性视图的筛选、分组、视图功能做统计（例如「本月看完的电影」）。
