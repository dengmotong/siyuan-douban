# 开发文档

> 面向二次开发 / 维护者。运行环境：Node 18+（CI 使用 Node 20）。

---

## 1. 技术栈

| 项 | 说明 |
| --- | --- |
| 构建 | Vite 5，输出 **CJS**（思源插件格式），`siyuan` 包始终 external，不打包 |
| UI | Svelte 4 单文件组件 |
| 语言 | TypeScript（`strict: false`，但 `noUnusedLocals` / `noUnusedParameters` 开启） |
| 样式 | SCSS，全局通过 `src/components/styles/main.scss` 聚合 |
| i18n | `public/i18n/*.json`（开发模式下由 `yaml-plugin.js` 支持 YAML → JSON） |
| 路径别名 | `@/` → `src/` |
| 测试 | 暂无自动化测试 |

## 2. 命令

```bash
npm install            # 安装依赖

npm run dev            # watch 构建 → dev/，带 inline sourcemap
npm run build          # 生产构建 → dist/，并打包 package.zip
npm run make-link      # 把 dev/ 软链到思源插件目录（需思源运行在 localhost:6806）
npm run make-link-win  # Windows 提权版软链
npm run make-install   # 构建 dist/ 并复制到思源插件目录
npm run sync           # 构建并复制到写死的 docker 插件目录（按需修改路径）
npm run update-version # 交互式升级 plugin.json + package.json 版本号
```

手动安装/调试：把 `dist/` 下的全部文件（`index.js`、`index.css`、`plugin.json`、`i18n/`、`icon.png`）放到
`工作空间/data/plugins/siyuan-douban/`，然后在思源里启用插件。

## 4. 数据流

### 4.1 书籍

```
输入 ISBN ──► fetchBookHtml()  ──► fetchDoubanBook(html)  ──┐
输入书名 ──► searchDoubanBooks()（弹窗选择）──► fetchBookHtml(subjectId) ──┘
                                                            │
                                                            ▼
                                            BookSearchTab 表单（可编辑）
                                                            │
                                     loadAVData(avID, fullData, plugin)
                                                            │
                    ┌───────────────────────────────────────┼────────────────────────────┐
                    ▼                                       ▼                            ▼
        补齐/清理属性视图列                        按 ISBN 去重                  createDocWithMd 生成笔记
```

- `fetchBookHtml(id)` 同时接受 **ISBN** 与**豆瓣 subject ID**，自动选择 `/isbn/` 或 `/subject/` 路径。
- 搜索走 `search.douban.com/book/subject_search`，解析页面内嵌的 `window.__DATA__` JSON；旧版页面回退到 DOM 解析。
- 所有豆瓣请求都通过思源内核 `/api/network/forwardProxy` 转发，因此**浏览器端可用**，不受跨域限制。

### 4.2 电影 / 电视剧

```
输入片名 ──► searchTMDBMovies / searchTMDBTvs（弹窗选择）
                          │
                          ▼
              fetchTMDBMovie / fetchTMDBTv（详情 + credits）
                          │
                          ▼
      MovieSearchTab / TvSearchTab 表单（我的评分、分类、状态、日期）
                          │
        loadAVMovieData / loadAVTvData(avID, fullData, plugin)
                          │
   补齐列 → 去重 → 下载封面 → 追加属性视图行 → 取回 blockID
                          │
                  生成观影 / 追剧笔记文档并挂到该行
```

- TMDB 请求优先走 `plugin.client.$fetch`（思源 SDK），无 SDK 时回退原生 `fetch`。
- 封面直接交给 `getImage()`，由内核 `forwardProxy` 下载后经 `/api/file/putFile` 落盘到 `assets/covers/`。

#### 4.2.1 电视剧分集笔记（可选分支）

勾选 `tvInfo.addEpisodeNotes` 后，`loadAVTvData()` 尾部会走 `generateEpisodeNotes()`：

```
fullData.addEpisodeNotes
        │
        ▼
fetchTMDBTvSeasons(tmdbId)          # /tv/{id} 拿季列表 → 逐季 /tv/{id}/season/{n}，并发 4
        │
        ▼
过滤 season_number === 0（特别篇）
        │
        ▼
逐集 createDocWithMd                # path = {数据库文档 hpath}/{剧名}/{第N季}/{第NN集 集标题}
        │                           # parentID = 数据库所在根文档，季文件夹由思源自动补建
        ▼
done 计数 → showMessage 进度（每 5 集）
```

- `tmdbId` 由 `fetchTMDBTv` 写入 `TvInfo.tmdbId`，旧数据回退从 `tmdbUrl` 正则提取。
- 集标题、季集号、时长、剧照等由 `renderEpisodeTemplate()` 渲染：先套用 `renderTvTemplate()`（整剧变量），再替换 `{{当前季}} {{当前集}} {{集标题}} …`。
- 分集文档**不绑定**数据库行（不写 `custom-avs`），只作为总笔记的子文档存在。
- 任一集创建失败只 `console.warn` 跳过，不影响其余集与整体返回码。
- 剧照使用 TMDB 远程 `w300` 地址，不做批量下载（避免上百次图片下载）。

### 4.3 微信读书

```
loginWeread.ts（扫码 / Cookie）
        │
        ▼
wereadInterface.ts（getNotebooks / getBook / getNotebook ...）
        │
        ▼
syncWereadNotes.ts（按模板渲染 → updateEndBlocks 写入位置标记之后）
```

## 5. 依赖的思源内核 API

| 接口 | 用途 |
| --- | --- |
| `/api/query/sql` | 通过块 ID 查数据库块，解析 `data-av-id` |
| `/api/av/getAttributeView` | 读取属性视图全部行数据（用于去重、取 blockID） |
| `/api/av/getAttributeViewKeysByAvID` | 读取列定义（`{id, name, type}`） |
| `/api/av/addAttributeViewKey` | 补齐缺失列 |
| `/api/av/removeAttributeViewKey` | 删除重复 / 废弃列 |
| `/api/av/appendAttributeViewDetachedBlocksWithValues` | 追加一行数据 |
| `/api/av/removeAttributeViewBlocks` | 清理孤立行 |
| `/api/av/setAttributeViewBlockAttr` | 把已有文档绑定到数据库行 |
| `/api/filetree/createDocWithMd` | 生成笔记文档 |
| `/api/attr/setBlockAttrs` | 写入 `custom-avs` 等自定义属性 |
| `/api/file/putFile`、`/api/file/getFile` | 上传封面、读写 `data/storage/av/{avID}.json` |
| `/api/network/forwardProxy` | 代理豆瓣 / 微信读书 / 图片请求 |
| `/api/ui/reloadAttributeView` | 刷新数据库视图 |

属性视图行的取值结构（`appendAttributeViewDetachedBlocksWithValues`）必须按列类型构造：

| 列类型 | 字段 |
| --- | --- |
| block | `block.content` |
| text | `text.content` |
| number | `number.{content, formattedContent, isNotEmpty}` |
| select | `mSelect: [{ content }]` |
| date | `date.{content(时间戳), isNotEmpty, isNotTime}` |
| url | `url.content` |
| mAsset | `mAsset: [{ content, type: "image" }]` |

## 6. TMDB 端点

| 用途 | 端点 |
| --- | --- |
| 电影搜索 | `GET /3/search/movie?query=&language=zh-CN&page=1` |
| 电影详情 | `GET /3/movie/{id}?language=zh-CN&append_to_response=credits` |
| 电视剧搜索 | `GET /3/search/tv?query=&language=zh-CN&page=1` |
| 电视剧详情 | `GET /3/tv/{id}?language=zh-CN&append_to_response=credits,external_ids` |
| 分季列表 | `GET /3/tv/{id}/season/{n}?language=zh-CN`（生成分集笔记时逐季拉取，并发 4） |

图片地址：海报 `https://image.tmdb.org/t/p/{w185|w500}{poster_path}`。

## 7. 如何新增一种媒体类型（以电视剧为参照）

按顺序新增 / 修改下列文件即可复制出完整链路：

1. **采集层** `src/utils/douban/<type>/`
   - `search<Type>.ts`：搜索接口 + `SearchResult` 结构
   - `fetch<Type>.ts`：详情接口 + `<Type>Info` 结构 + 解析函数
   - `index.ts`：统一导出
2. **持久化层** `src/utils/<type>Handling/`
   - `index.ts`：`loadAV<Type>Data(avID, fullData, plugin)`，包含列补齐、去重、封面、追加行、生成笔记
   - `changeMainKeyName.ts`：把主键列改名
3. **UI 层**
   - `src/components/tabs/<Type>SearchTab.svelte`：录入表单（可直接以 `TvSearchTab.svelte` 为模板）
   - `src/components/common/search<Type>Dialog.svelte`：搜索结果弹窗
4. **主面板** `src/components/index.svelte`
   - 新增状态块、`fetch<Type>Data()`、`handleAdd<Type>()`、`validate<Type>DatabaseID()`
   - `tabs` 数组插入新标签（**注意后续 `activeTab === tabs[n]` 的下标要整体后移**）
   - `handleSaveSettings()` / `onMount()` 里读写新设置
   - 末尾挂载搜索弹窗与模板编辑器
5. **设置页** `src/components/tabs/UserSettingsTab.svelte`：新增数据库 ID、下拉选项、模板按钮
6. **i18n** `public/i18n/zh_CN.json`、`en_US.json`：新增 `topTabnameN` 与 `<type>*` 文案
7. **模板示例**：仓库根目录补一份 `xxx笔记模板.md` 作为示例

> ⚠️ `noUnusedLocals` 已开启，新增未使用的导入会导致构建报错。

## 8. i18n

- 文案文件：`public/i18n/zh_CN.json`、`public/i18n/en_US.json`，键名一致。
- 组件内通过 `i18n.<key>` 访问，通常写法是 `i18n.xxx || "中文兜底"`。
- 新增键时**两个语言文件都要加**，并保持 JSON 缩进 4 空格、`ensure_ascii=False`（直接写中文，不要 `\uXXXX`）。

## 9. 设置持久化

设置保存在 `工作空间/data/storage/petal/siyuan-douban/settings.json`：

```jsonc
{
  // 书籍
  "bookDatabaseID": "", "noteTemplate": "", "ratings": [], "categories": [], "statuses": [],
  "addNotes": true, "isSYTemplateRender": false,
  // 电影
  "movieDatabaseID": "", "movieNoteTemplate": "", "movieRatings": [], "movieCategories": [], "movieStatuses": [],
  // 电视剧
  "tvDatabaseID": "", "tvNoteTemplate": "", "tvEpisodeNoteTemplate": "",
  "tvRatings": [], "tvCategories": [], "tvStatuses": [],
  // 公用
  "tmdbApiKey": ""
}
```

`isSYTemplateRender` 为全局开关，同时作用于三套笔记模板。

## 10. 与上游同步

本仓库的远程配置：

| remote | 地址 | 用途 |
| --- | --- | --- |
| `upstream` | `https://github.com/Glaube-TY/siyuan-douban` | 原作者的仓库 |
| `fork` | `https://github.com/dengmotong/siyuan-douban` | 本仓库（fork） |

分支策略：

- `fork/main` = 上游最新代码，**不做改动**，仅用于对比 / 合并。
- `web-movie-tv` = 本项目的改造分支（网页版适配 + 电影 + 电视剧 + 文档），日常开发在这里。

拉取上游更新：

```bash
git fetch upstream
git log --oneline upstream/main ^web-movie-tv   # 看上游有哪些新提交
git merge upstream/main                          # 或 git rebase upstream/main
```

> 注意：本项目基于上游 v2.8.1，上游后续版本改动较大（v4.x 重写过微信读书同步），
> 直接 merge 大概率冲突，建议**按需挑选单个提交**（`git cherry-pick`）而不是整分支合并。

## 11. 发布

`.github/workflows/release.yml` 在推送 `v*` 标签时触发：

```bash
npm run update-version     # 升级 plugin.json + package.json 版本号
git commit -am "release: vX.Y.Z"
git tag vX.Y.Z
git push fork web-movie-tv --tags
```

CI 会执行 `pnpm install && pnpm build`，并把 `package.zip` 上传为 Release 产物。
思源要求 `plugin.json` 与 `package.json` 的 `version` 保持一致。

## 12. 已知限制

- **无自动化测试**：改动后请手动在思源中验证（建议至少跑一遍「建库 → 添加 → 生成笔记」）。
- **移动端**：快捷键打开插件仅桌面端可用；扫码登录依赖 Electron，移动端/浏览器端请用 Cookie。
- **TMDB 需要 API Key**，且 TMDB 在部分网络环境下需要代理。
- **豆瓣反爬**：搜索页结构与 `window.__DATA__` 格式可能变化，变化后需更新 `searchBook.ts` 的解析逻辑。
- **主键改名**依赖直接改写 `data/storage/av/{avID}.json`，在无写权限环境会静默失败（仅日志报错）。
